# ID-SEAD Validation V2

This folder contains a **separate, study-aware validation layer** for the ID-SEAD adsorption project. It does not modify the original notebooks or submitted manuscript.

## Why this exists

The literature-derived dataset contains multiple rows from the same source paper. An ordinary random row split can therefore put closely related experiments from one study into both train and test sets. That can overstate generalisation to unseen studies.

The first V2 harness compares:

1. shuffled row-wise K-fold validation; and
2. source-grouped K-fold validation, where no `source_link` group can appear in both training and validation for a fold.

## Scientific guardrails in the first harness

- `source_link` is **never** a predictor; it is only the grouping key.
- `removal_percent` is excluded because it can be algebraically related to adsorption capacity and may leak target information.
- imputation, scaling and one-hot encoding are fit **inside each training fold** through sklearn `Pipeline`/`ColumnTransformer`.
- missing numeric values are handled conservatively; textual values such as `~25` and simple numeric ranges are parsed explicitly.
- confidence intervals are generated by resampling **whole study groups**, not individual rows.
- random-split source overlap is measured and written to an audit file.

## Run

From the repository root:

```bash
python validation_v2/study_aware_validation.py
```

Optional XGBoost support is used when `xgboost` is installed.

## Outputs

Generated files are written under `validation_v2/outputs/`:

- `dataset_leakage_audit.json` — number of independent study groups and the extent of source overlap under a legacy-style random 80/20 partition.
- `study_group_counts.csv` — rows contributed by each normalized source.
- `random_vs_grouped_cv.csv` — R², RMSE, MAE and study-cluster bootstrap intervals under random vs grouped validation.
- `cross_validated_predictions.csv` — out-of-fold predictions for forensic comparison.

## Interpretation rule

Do **not** treat a large drop from random CV to grouped CV as a software failure. It is evidence that row-wise validation was benefiting from within-study similarity. The grouped result is the more relevant estimate when the claim concerns generalisation to unseen literature studies.
